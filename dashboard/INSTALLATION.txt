- KPI du Market Explorer répartis sur toute la largeur du graphique
- filtres et légende réorganisés sans perdre leur logique
- cartes Qwen / Accord / Heuristique stylisées

Installation :
1. Sauvegarder dashboard/src avant toute copie.
2. Copier le contenu de src/ dans C:\Users\xavie\qwen-trading\dashboard\src\
3. Depuis dashboard : pnpm exec tsc --noEmit
4. Relancer pnpm dev si nécessaire et vérifier la navigation, les filtres et les inspecteurs.

Note : compilation complète avec vos node_modules Windows non exécutée ici.
